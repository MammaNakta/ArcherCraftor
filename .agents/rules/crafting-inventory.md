# ArcherCraftor 현장 즉석 제작 & 퀴버 시스템 규칙

## 1. 화살 및 탄약 규칙
1. **기본 화살 (Standard Arrow)**:
   - 무한 탄약.
   - 좌클릭 속사/차징으로 발사.
2. **특수 화살 (Special Crafted Arrows)**:
   - 월드에서 실시간 채집/루팅한 재료로 조합.
   - 슬롯당 스택 한도(기본 10발).
   - 우클릭 속사/차징으로 발사.
   - 마우스 휠 스크롤로 선택 탄종 즉시 변경.

## 2. 특수 화살 조합표 (Recipe Specification)

| 특수 화살 | 소모 재료 (1발당) | 발사 기믹 (속사 vs 차징) |
| :--- | :--- | :--- |
| **충격 화살 (Impact)** | 기본화살 1 + 충격석(부싯돌) 1 | 속사: 적 넉백 / 차징: 벽 충돌 시 광역 기절 |
| **화염 폭발 화살 (Blast)** | 기본화살 1 + 화염 열매 1 | 속사: 소형 폭발 / 차징: 대형 화염 장판 지속딜 |
| **서리 속박 화살 (Frost)** | 기본화살 1 + 서리 버섯 1 | 속사: 이동속도 70% 둔화 / 차징: 주변 광역 빙결 |
| **번개 연쇄 화살 (Spark)** | 기본화살 1 + 정전기 결정 1 | 속사: 연쇄 방전 탄막 소거 / 차징: 착탄 대상 낙뢰 |

## 3. 즉석 조합(Quick-Craft) UX 동작
- 잔여 특수 화살이 0발인 상태에서 우클릭 발사 시도시, 재료가 충분하면 즉시 1발을 현장 제작하여 딜레이 없이 발사해야 합니다.
- `Q` 키 또는 `E` 키를 누르면 현재 선택된 화살을 보유 재료 한도 내에서 일괄 제작합니다.
